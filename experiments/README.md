# Experiments

Experiments must be reproducible, equal-budget where claimed, and explicit about every mechanism that can influence outcomes.

The initial ablation ladder is:

1. single trajectory;
2. parallel independent trajectories;
3. single-trajectory self-reflection;
4. cross-trajectory comparative reflection;
5. persistent insight injection;
6. differentiated replanning;
7. reward-oriented context consolidation.

Each run should preserve configuration, immutable input hashes, model and runtime versions, token accounting, wall time, verifier evidence, final verdict, and the full state-transition trace.
