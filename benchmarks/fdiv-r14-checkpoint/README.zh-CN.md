# FDIV R14 Checkpoint 适配目录

[English](README.md) | 简体中文

本目录为 FDIV R14 Checkpoint 实验预留公开适配边界，当前有意不包含 RTL、Lean Spec、生成证明或历史 Trace。

源 Case 目前保存在单独进行版本管理的私有 Benchmark 仓库中。在所有输入具备明确来源、再分发授权、不可变 Hash 和逐 Case 许可证之前，不得复制到这里。该门禁可以防止软件重构过程中意外公开无关的 Benchmark 材料。

来源门禁完成后，本目录将提供符合 [`benchmarks/README.zh-CN.md`](../README.zh-CN.md) 的干净 `0/14` 或明确声明的 Checkpoint Case。在此之前，本目录没有 `case.json`，有意不出现在 `chip_proof_cases` 中，也不能由仅支持实验模式的 Runtime 启动。已授权 Case 提交到这里后，再遵循[复现实验协议](../../experiments/fdiv-reproduction/README.zh-CN.md)。
